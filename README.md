# saga

A strongly-typed saga/DAG orchestrator for Gleam: typed dependency graphs instead of dynamic step maps.

Status: design-stage; see [saga-design.md](https://github.com/gleam-dream/oversight/blob/master/saga-design.md) in [gleam-dream/oversight](https://github.com/gleam-dream/oversight). Not yet published to Hex.

Ports/wraps: Reactor (Elixir).

## Development

```sh
nix develop
gleam test
```
